# Testandi

Testandi is a comprehensive, privacy-first financial calculator mobile application built with React Native and Expo. It provides investors, students, and financial professionals with quick access to industry-standard financial models and valuation metrics right from their mobile devices.

## Features

Testandi includes 13 robust financial calculators:
*   **Jensen's Alpha:** Measure a portfolio's risk-adjusted performance against a benchmark index.
*   **Buffett Ratio:** Compare total market capitalization to GDP to assess market valuation.
*   **Capital Asset Pricing Model (CAPM):** Describe the relationship between systematic risk and expected return.
*   **Capitalization of Earnings Model:** Calculate required portfolio balances for targeted passive income.
*   **Debt to Income Ratio (Housing Ratio 2):** Evaluate total monthly debt obligations relative to gross income.
*   **Dividend Discount Model (DDM):** Value stocks based on predicted future dividends.
*   **Effective Annual Rate (EAR):** Measure the actual annual interest rate with frequent compounding.
*   **Expected Value (EV):** Calculate probability-weighted averages of potential outcomes.
*   **Income-Based Real Estate Valuation:** Estimate real estate value based on NOI and cap rates.
*   **Net Present Value (NPV):** Determine the current value of future cash flows.
*   **Sample Standard Deviation:** Measure variation in historical returns.
*   **Sharpe Ratio:** Understand investment return compared to its risk.
*   **Value at Risk (VaR):** Estimate the maximum potential loss of a portfolio.

**Additional Features:**
*   **Local Storage:** Save your calculation history directly to your device. 
*   **Cross-Platform:** Beautifully designed for both iOS and Android platforms.

## Getting Started

### Prerequisites

*   Node.js (LTS recommended)
*   npm or yarn
*   Expo CLI (`npm install -g expo-cli`)
*   iOS Simulator (Mac only) or Android Emulator for testing

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/testandi.git
   cd testandi
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the Expo development server:
   ```bash
   npm start
   ```

### Running the App
*   Press `i` in the terminal to open in the iOS simulator.
*   Press `a` to open in the Android emulator.
*   Scan the QR code with the Expo Go app on your physical device.
